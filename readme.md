# Personal Portfolio Website

Website portofolio pribadi multi halaman yang dibuat untuk latihan HTML, CSS, dan JavaScript.

## Tujuan
Melatih pembuatan halaman website yang saling terhubung, menjaga konsistensi tampilan, dan menerapkan interaksi JavaScript sederhana.

## Fitur
- Empat halaman: Home, About, Projects, dan Contact.
- Navbar yang tersedia di semua halaman dengan penanda halaman aktif.
- Filter proyek kategori Semua, HTML/CSS, dan JavaScript tanpa reload.
- Validasi nama, format email, dan pesan pada formulir dalam laman Contact.
- Notifikasi kesalahan atau validasi berhasil.

## Cara menjalankan
1. Unduh atau clone repository.
2. Buka folder proyek.
3. Buka `index.html` di browser menggunakan local host.
4. Buka halaman Projects untuk mencoba filter.
5. Buka halaman Contact untuk mencoba validasi formulir.
